The quiz

FZT 203E · Quiz 1 · 20 points (5 per problem)

Products are read right to left: in gh, h acts first. In D₃, r = (123), s = (23), so rs = (12) and r²s = (13).

1. Permutations and D₃ (5 points)

  1. Compute σ = (13)(123) and τ = (123)(13). (2 pts)

    For σ, (123) acts first: 1 → 2 → 2, 2 → 3 → 1, 3 → 1 → 3. So σ = (12).

    For τ, (13) acts first: 1 → 3 → 1, 2 → 2 → 3, 3 → 1 → 2. So τ = (23).

    The two products differ, so (13) and (123) do not commute.

  2. Write σ and τ in the normal form rksm. (1 pt)

    σ = (12) = rs and τ = (23) = s.

    Check with the relations: (13) = r²s and (123) = r, so σ = r²s · r = r² · r⁻¹s = rs, using sr = r⁻¹s; and τ = r · r²s = r³s = s.

  3. Is H = {e, (12), (13)} a subgroup of S₃? (2 pts)

    No: H is not closed. (12)(13) sends 1 → 3 → 3, 3 → 1 → 2, 2 → 2 → 1, so (12)(13) = (132), which is not in H.

    Lagrange's theorem alone does not settle it, since 3 divides 6. Another way to see it: a group of order 3 is cyclic, generated by an element of order 3, but (12) and (13) have order 2.

2. Cosets in Z₉ (5 points)

  1. The order of 6 in Z₉ and the subgroup ⟨6⟩. (1 pt)

    6, 6 + 6 = 12 = 3, 3 + 6 = 9 = 0. So 6 has order 3 and ⟨6⟩ = {0, 3, 6}.

  2. The distinct cosets k + H and the index [Z₉ : H], with H = ⟨6⟩. (2 pts)

    0 + H = {0, 3, 6}, 1 + H = {1, 4, 7}, 2 + H = {2, 5, 8}. Every other k gives one of these, since k + H depends only on k mod 3.

    [Z₉ : H] = 3, in agreement with Lagrange: 9 / 3 = 3.

  3. Is 2 + H = 8 + H? Is 1 + H = 5 + H? (2 pts)

    2 − 8 = −6 = 3 in Z₉, and 3 ∈ H, so 2 + H = 8 + H (both are {2, 5, 8}).

    1 − 5 = −4 = 5 in Z₉, and 5 ∉ H, so 1 + H ≠ 5 + H ({1, 4, 7} and {2, 5, 8}).

3. What Lagrange's theorem tells us (5 points)

  1. |G| = 35. Which of 2, 5, 7, 10 are ruled out as element orders? (2 pts)

    The order of an element is the order of the cyclic subgroup it generates, so it divides 35 = 5 · 7. The divisors are 1, 5, 7, 35. 2 and 10 are ruled out; 5 and 7 are not.

  2. |G| = 11 and H ≤ G with H ≠ {e}. Show that H = G. (1 pt)

    By Lagrange, |H| divides 11, which is prime, so |H| = 1 or 11. H ≠ {e} rules out |H| = 1, so |H| = 11 = |G|, and since H ⊆ G, H = G.

  3. True or false: every group of order 8 contains an element of order 8. (2 pts)

    False. Lagrange only says element orders divide 8; it does not say every divisor occurs. Counterexample: Z₂ × Z₂ × Z₂, the triples of 0s and 1s added componentwise mod 2. It has 8 elements, and every element g satisfies g + g = 0, so every element other than 0 has order 2.

    A group of order 8 has an element of order 8 exactly when it is cyclic, like Z₈.

4. A homomorphism Z₆ → Z₉ (5 points)

φ : Z₆ → Z₉, φ([k]₆) = [3k]₉.

  1. φ is well defined and preserves addition. (2 pts)

    Well defined: if [k]₆ = [k′]₆, then k′ = k + 6m for some integer m, so 3k′ = 3k + 18m. Since 9 divides 18m, [3k′]₉ = [3k]₉: the image does not depend on the representative. (Equivalently, going once round Z₆ adds 6 · 3 = 18 = 0 in Z₉.)

    Preserves addition: φ([k]₆ + [l]₆) = φ([k + l]₆) = [3k + 3l]₉ = [3k]₉ + [3l]₉ = φ([k]₆) + φ([l]₆).

  2. ker φ and im φ. (2 pts)

    The images of 0, 1, 2, 3, 4, 5 are 0, 3, 6, 0, 3, 6.

    ker φ = {0, 3} (3k is a multiple of 9 exactly when 3 divides k) and im φ = {0, 3, 6}. Check: |ker φ| · |im φ| = 2 · 3 = 6 = |Z₆|.

  3. Is φ injective? (1 pt)

    No. A homomorphism is injective exactly when its kernel is {0}, and here ker φ = {0, 3}. For example φ(0) = φ(3) = 0.
