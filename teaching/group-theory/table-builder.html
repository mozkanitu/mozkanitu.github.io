    Two groups with four elements

    Both tables have four rows and four columns. In Z4 the diagonal holds e only twice, because r has order 4. In the cuboid group every diagonal entry is e: each element is its own inverse, so no element has order 4. No relabeling turns one table into the other, so the two groups are not isomorphic.
