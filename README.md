# Mehmet Özkan – personal and group website

Static site served by GitHub Pages. No build step: every page is plain HTML.

* `index.html` and the folders `research/`, `publications/`, `projects/`, `group/`, `teaching/` hold one page each.
* `teaching/group-theory/` holds the course page, the lecture notes (`notes/`) and the three simulations.
* Shared style and script: `assets/site.css`, `assets/site.js`. The paper list and the course schedules are data at the top of `assets/site.js`.
* Visitor statistics: put the GoatCounter code into `assets/analytics.js`.
